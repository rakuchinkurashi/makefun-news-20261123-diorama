Entry for the [make.fun bounty "Sum up 23 November's world news in one image"](https://make.fun/bounty/news-image-20261123).

## The six stories

- **Benghazi:** Zelenskyy says Ukraine sank the Russian corvette Merkury in Benghazi port with 7 sea drones. Cargo ship MV Angara was also attacked; a Ka-27 helicopter was destroyed.
- **US targets Iranian shadow banking:** More than two dozen targets sanctioned; about $14.7 billion in related activity.
- **NATO sends AWACS to Poland:** NATO to deploy AWACS after 3 Russian Kh-101 missiles fell in Poland.
- **Asian chip stocks plunge:** KOSPI fell as much as -5.8%, closed -3.3%. Samsung -3.1%, SK hynix -2.5%. S&P 500 -3.7%, Nasdaq -5.3%.
- **Huang returns as NVIDIA CEO:** The board reinstates Jensen Huang, 11 days after his resignation. The vote was unanimous.
- **Yemen bus attack: blame disputed:** A bus and truck were attacked in Lahj; civilian casualties; responsibility disputed. No death toll is given, because sources disagree on the number.

Every number in the image was verified against reporting on the day; no unverified figure is used.

## How it works

Run `python3 main.py` — it copies `news.png` (1024×1024) to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere. The program is deterministic: no network, no randomness, no timestamps, so two runs write byte-identical files.
